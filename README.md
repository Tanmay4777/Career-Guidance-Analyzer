## 📌 Project Overview

The **AI Career Guidance Assistant** is an intelligent conversational platform designed to assist students and early-career developers in discovering tech career paths, analyzing requisite industry skill sets, exploring market compensation benchmarks, and preparing for technical interviews.

---

## ✨ Features Implemented

### **Core Features**
* ✅ **Greeting & Introduction:** Context-aware onboarding dialogue establishing guided session flows.
* ✅ **Career Path Exploration:** Multi-domain deep dives across AI & NLP, Data Science, and Computer Vision.
* ✅ **Skill Requirement Analysis:** Detailed prerequisite breakdowns from foundational programming to production tools.
* ✅ **Industry Trends Insights:** Real-time growth tracking highlighting in-demand tech domains and adoption rates.
* ✅ **Profile-Based Recommendations:** Dynamic matching connecting student interests with aligned career specializations.
* ✅ **Career Path Guidance:** Sequential, step-by-step career milestone roadmaps.

### **Bonus Features**
* ⭐ **Salary Insights:** Entry- to mid-level compensation benchmarking across diverse technical tracks.
* ⭐ **Job Market Predictions:** Year-over-year (YoY) sector hiring growth metrics.
* ⭐ **Company Research:** Curated directories of top global and domestic firms actively hiring for target profiles.
* ⭐ **Interview Preparation Tips:** Curated technical, architectural, and behavioral interview strategies.
* ⭐ **Career Goal Setting Tracker:** Interactive visual milestone progress tracking toward industry readiness.
* ⭐ **Interactive Visualization Dashboard:** Integrated **Chart.js** bar graph displaying tech compensation ranges.
* ⭐ **Web API Backend:** Python Flask REST service for conversational intent recognition and structured data delivery.
